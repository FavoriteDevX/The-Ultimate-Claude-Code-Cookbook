# 🍹 The Drinks Menu (Automated Documentation)

Light, refreshing, and satisfying utilities to keep your codebase beautifully documented without breaking a sweat.

---

### 🍸 Recipe 1: The Freshly Squeezed README Generator
* **Description:** Sweeps your codebase to understand what the project does and writes a beautiful, updated root README.md.
* **Ingredients:** Comprehensive project files, structural tree.
* **The Command:**
```bash
claude "Scan the repository layout, read the main entry points, and write a highly professional, user-friendly README.md file at the root containing installation steps, architecture overview, and usage examples."
```

### 🍷 Recipe 2: The Vintage JSDoc/Docstring Pour
* **Description:** Adds elegant, standardized documentation headers to every naked function or class in a file.
* **Ingredients:** `[PATH_TO_TARGET_FILE]`, `[DOC_STYLE]` (e.g., JSDoc, Google Style, Sphinx).
* **The Command:**
```bash
claude "Inspect [PATH_TO_TARGET_FILE]. Without changing a single line of execution logic, inject comprehensive [DOC_STYLE] comments above every public function, class, and interface detailing parameters, types, and return values."
```
